OCTO BIRD Benchmark Report

This page is only about BIRD. It shows OCTO's current full-dev grounding result, the actual lift from the evidence-aware path, and the current official BIRD leaderboard context.

Read this correctly: OCTO's current 0.926 is a grounding accuracy result on BIRD dev. The official BIRD leaderboard numbers like 81.95 are end-to-end execution accuracy. They are not the same metric.

What The OCTO Number Means

Grounding accuracy here means a question counts as correct only when all gold tables are present in the candidate table set produced by the grounding stage.

So 0.926 means that on 92.6% of BIRD dev questions, the evidence-aware OCTO path recovered every gold table somewhere in its candidate set.

It does not mean OCTO solved 92.6% of BIRD end to end.

Why This Still Matters

If grounding is wrong, SQL generation is usually dead on arrival. OCTO is currently strongest as an upstream world-coprocessor that improves recall of the right schema objects before generation.

The meaningful current claim is not “we beat the BIRD leaderboard.” The meaningful claim is “we improve the grounding stage on full BIRD dev when evidence is available.”

Actual Lift Over The Baseline

+0.063 Absolute grounding accuracy lift for octo_with_evidence over schema_only.
+0.031 Absolute average table recall lift over schema_only.
-0.016 Absolute top-1 hit change. This got slightly worse, which suggests broader recall rather than better rank-1 precision.

Bottom-Line Reading

Good news: OCTO has a real full-dev BIRD result. The evidence-aware path moves grounding accuracy from 0.864 to 0.926 across 1534 dev tasks.

Weak news: plain metadata enrichment alone does nothing here; octo equals schema_only.

Serious next step: convert this grounding lift into an end-to-end SQL execution benchmark. Until then, this report should be read as evidence that OCTO improves schema grounding, not as proof that it beats the current BIRD leaderboard.
