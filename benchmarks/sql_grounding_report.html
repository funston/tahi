Interpretation

BIRD shows the cleanest current OCTO lift: octo_with_evidence reaches 1.000 grounding accuracy on the local tiny slice, while plain octo matches schema_only at 0.900. That means the gain is coming from OCTO consuming task evidence through the world-coprocessor path, not from world metadata alone.

Gretel is useful as a fast add-on benchmark, but on the current 100-row frozen sample OCTO matches the schema_only grounding baseline rather than exceeding it. That is still useful because it shows we are not manufacturing a synthetic win with light metadata decoration.

The BIRD official leaderboard numbers above are execution-accuracy references from the public benchmark. They should be read as external context, not as apples-to-apples comparisons with the grounding metrics on this page.

These are grounding benchmarks, not end-to-end SQL execution benchmarks.
